# Morning Practice App

A personal morning practice tracker for strength, fascia release, walking, and nutrition.

## How to deploy to GitHub Pages

1. Go to [github.com](https://github.com) and create a new repository
   - Name it anything, e.g. `morning-practice`
   - Set it to **Public**
   - Click **Create repository**

2. Upload files — click **Add file → Upload files** and upload:
   - `index.html`
   - `icon.png` (optional, for home screen icon)

3. Enable GitHub Pages:
   - Go to **Settings → Pages**
   - Under **Source**, select **Deploy from a branch**
   - Branch: **main** / folder: **/ (root)**
   - Click **Save**

4. Your app will be live at:
   `https://YOUR-USERNAME.github.io/morning-practice`

## Add to iPhone home screen

1. Open the URL above in **Safari**
2. Tap the **Share** button (box with arrow)
3. Tap **Add to Home Screen**
4. Tap **Add**

It will appear as an app icon on your home screen with no browser chrome.
